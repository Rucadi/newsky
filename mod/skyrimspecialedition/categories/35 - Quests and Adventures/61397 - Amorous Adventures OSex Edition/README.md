# Amorous Adventures OSex Edition
- Author: Foxfingers
- Game: skyrimspecialedition
- Mod Page: https://www.nexusmods.com/skyrimspecialedition/mods/61397


![](https://staticdelivery.nexusmods.com/images/110/9749451-1504679471.jpg)
  
  
This is a version of Foxfingers' Amorous Adventures that uses OSex to animate it's romantic encounters. Credit goes entirely to the amazing Foxfingers, all I did was some trivial papyrus changes. Amorous Adventures is the greatest Skyrim romance quest mod of all and if you haven't tried it yet I highly recommend it! 
  
  
Any translation or addition to Amorous Adventures will also work with this!
